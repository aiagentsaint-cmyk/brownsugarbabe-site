# Brown Sugar Babe Review Mockup

This folder is ready to upload to GitHub and deploy with Vercel.

## Folder structure

Keep these files together exactly like this:

```text
index.html
assets/
  bsb-legs.png
  french-kiss-banner.jpg
README.md
```

`index.html` is the homepage. The `assets` folder must stay beside it because the page loads the collection images from `assets/bsb-legs.png` and `assets/french-kiss-banner.jpg`.

## Upload to GitHub

1. Create a new GitHub repository.
2. Open the repository.
3. Choose **Add file** then **Upload files**.
4. Drag the contents of this folder into GitHub, including `index.html`, `README.md`, and the full `assets` folder.
5. Commit the files.

## Deploy with Vercel

1. Go to Vercel.
2. Choose **Add New** then **Project**.
3. Import the GitHub repository.
4. Leave the build settings empty/default because this is a static HTML site.
5. Deploy.

After deployment, Vercel will give you a review URL. Future edits can be made by updating the GitHub files; Vercel will redeploy automatically.
